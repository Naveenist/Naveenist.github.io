01 / PHASES
The process

Three phases, no guesswork

01 Phase 1

Topic selection & architecture planning

We help you pick a feasible, examiner-friendly topic and map out the system architecture, database schema, and stack before a single line of code is written.

  • Topic feasibility review
  • System architecture diagram
  • Database schema design
  • Tech stack finalisation
02 Phase 2

Hands-on building & implementation

Build the project step by step alongside a mentor — live coding sessions, structured code reviews, and debugging support the whole way.

  • Guided live coding sessions
  • Weekly code reviews
  • Debugging & troubleshooting support
  • Version control best practices
03 Phase 3

Documentation & viva preparation

Walk into your viva with a polished presentation, a complete project report, and mock defence sessions already behind you.

  • Presentation deck (PPT)
  • Full written project report
  • Mock viva Q&A sessions
  • Common-question cheat sheet
02 / PACKAGES
Guidance levels

Pick how much support you need

Every level includes the complete working source code. The difference is how much of the explaining we do with you.

Level 01

Code only

The complete, working source code with a setup guide. Best if you are confident reading and extending an existing codebase.

  • Full source code
  • Setup & run instructions
  • Ownership transferred on delivery
Level 02

Code + training

Everything above, plus live walkthrough sessions so you understand every module well enough to change it yourself.

  • Everything in Code only
  • Live architecture walkthrough
  • Module-by-module code review
  • Minor revisions included
Level 03

Code + training + report

The full package — code, training, written documentation, presentation deck, and mock viva sessions.

  • Everything in Code + training
  • Full written project report
  • Presentation deck
  • Mock viva Q&A
